# Combat & training SFX

Generated by `tools/gen_sfx.py` (pure stdlib synthesis, deterministic —
`random.seed(cue)`). One `.ogg` per `SoundCue` in
`lib/core/platform/game_audio.dart`, basename = the cue's `name`. `ffmpeg`
must be on PATH when generating (the script writes WAV then transcodes;
raw WAVs would exceed the 150 KB bundle budget).

To retune a cue: edit its branch in `recipe()` in `tools/gen_sfx.py` and
re-run `python3 tools/gen_sfx.py`.
